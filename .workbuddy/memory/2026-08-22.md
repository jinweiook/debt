## TiDB Cloud 接入修复

- 用户在 tidbcloud.com 创建了 Serverless 集群，写入 .env.local 后报连接失败
- 根因：`.env.local` 里 `DB_NAME=sys`（TiDB 默认显示的库），`sys` 是系统库不能存业务数据
- 修复：通过 root 账号连 sys 库执行 `CREATE DATABASE debt CHARACTER SET utf8mb4` → 改 .env.local `DB_NAME=debt`
- 顺便验证：用户名/密码/host/port/SSL/TLS 全部正确
- 之后跑 `npm run db:reset && db:seed && verify`：TiDB 上 29/29 业务断言通过
- 服务已重启指向 TiDB（http://localhost:3777）

## Hydration 错误修复
- 报错：`<Router>` 子节点 SSR/客户端 HTML 不一致
- 根因：ToastProvider 用 `typeof document !== "undefined" && createPortal(...)` → 服务端不渲染 portal，客户端渲染
- 修法：`mounted` state + useEffect，hydration 完成后挂载 portal
- 顺手把三个表单的 `useState(new Date()...)` 改成 `useState("")` + useEffect，避免跨午夜漂移

## 动态年化利息特性
- 用户要求：分期支持"按剩余本金 × 年化 ÷ 12"动态算月息
- Schema：`debt_accounts` 新增 `interest_mode`（fixed/dynamic）和 `dynamic_plan`（equalPrincipal/interestOnly/equalPayment）

- 还款后 `recomputeDynamicBills` 重算后续账单，用 `cumulativePaidPrincipal` 驱动剩余本金
- 已还清的账单不重算，避免与 paidCents 不变量冲突
